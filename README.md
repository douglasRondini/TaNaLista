# 🛒 Tá na Lista

**Tá na Lista** é um aplicativo de lista de compras inteligente, criado para resolver aquele clássico momento: *“minha mulher mandou comprar”*.  
Com ele, você organiza suas compras de supermercado de forma prática, rápida e sem esquecer nada.

---

## ✨ Funcionalidades
- Criação e gerenciamento de listas de compras.
- Organização por categorias (frutas, proteínas, básicos etc.).
- Integração com banco de dados Room para salvar e recuperar itens.
- Filtro por categoria com título dinâmico na tela principal.
- Interface simples e intuitiva para adicionar, editar e remover itens.
- Histórico de compras e próximas compras planejadas.

---

## 🛠️ Tecnologias utilizadas
- **Kotlin** para desenvolvimento Android.
- **Room Database** para persistência local.
- **MVVM Architecture** para separação de responsabilidades.
- **LiveData** e **ViewModel** para reatividade.
- **RecyclerView** com Adapter genérico para exibição dos itens.
